# Tattva Technology website

This is a static multi-page website. The homepage is `index.html` and is served at the root URL.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `careers.html` — Careers
- `contact.html` — Contact

## Deploy
Upload the contents of this folder to your existing hosting project (keep the `assets`, `css`, and `js` folders). For Vercel, import the project as a static site with no build command and the project root set to this folder. The `vercel.json` file no longer rewrites `/` to the coming-soon page.

The original site address is controlled by your hosting/domain settings; this ZIP preserves the website files but cannot change DNS or deploy the site by itself.
